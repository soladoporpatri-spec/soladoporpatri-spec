## 📂 Alguns projetos que desenvolvi

### 🤖 [Nythar — Dashboard & Chatbot](https://github.com/soladoporpatri-spec/Nythar-Dashboard-Chatbot)

Um projeto voltado para facilitar a rotina de negócios. A ideia é reunir em um só lugar um painel administrativo e um chatbot para WhatsApp, com recursos como agendamentos, cadastro de clientes, relatórios financeiros e atendimento automatizado.

**Tecnologias:** C#, JavaScript, Docker e integração com WhatsApp.

### 🛒 [Sitetec](https://github.com/soladoporpatri-spec/Sitetec)

Uma aplicação web para apresentar e gerenciar produtos e serviços de forma dinâmica. O projeto é dividido entre frontend e backend, com foco na organização e na manutenção do sistema.

**Tecnologias:** Next.js, React e TypeScript.

### 👓 [Ótica VIP Anápolis](https://github.com/soladoporpatri-spec/Otica)

Um projeto para o setor óptico que explora a visualização 3D de óculos. A proposta é tornar a experiência de quem visita a plataforma mais interativa, permitindo apresentar os produtos de uma maneira diferente.

**Tecnologias:** Vite, Three.js e JavaScript.

### 🚗 [Lavajato](https://github.com/soladoporpatri-spec/Lavajato)

Um projeto para um lava-jato, com uma página de apresentação moderna e recursos voltados para o gerenciamento do negócio. Também trabalhei na adaptação da interface para diferentes tamanhos de tela.

**Tecnologias:** Next.js, React e TypeScript.
